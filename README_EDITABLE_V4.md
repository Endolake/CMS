# Editable CMS v4

This Studio adds much broader website editing. New singleton sections: About Page, Services Page, Contact Page, Appointment Page, Referral Form Page. Practice & Site Settings now includes logo, navigation labels, footer text, and default SEO. Existing Homepage, Patients, Referring Doctors, Doctor, Services, and Office sections are expanded/preserved.


Referral form: upload/replace the PDF at **For Referring Doctors → Referral Form PDF**, then Publish. The public website download link updates automatically.

# Lake Forest Endodontics — Sanity Studio

This is the browser-based CMS for Lake Forest Endodontics.

## Project
- Sanity project ID: h0i5f2pn
- Dataset: production
- Netlify Studio: https://lakeforestadmin.netlify.app/

## CMS sections
- Practice Information
- Homepage
- Doctor
- Services
- For Patients
- For Referring Doctors
- Office & Photos

## Important
This version uses the current Sanity Studio 6 package family and React 19.2 so it is compatible with Sanity UI 4 and Netlify Node 22.12.

The public website is a separate project and is not automatically connected to this Studio until the frontend is configured to read the Sanity Content Lake.
